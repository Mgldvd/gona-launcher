# Gona Launcher docs

Gona Launcher is a highly configurable app launcher for [Omarchy](https://omarchy.org): apps live in tiles laid out as a
split tree, in a Quickshell (QML) plugin that runs inside the Omarchy shell. These pages describe the
current plugin (Omarchy 4.0, Quickshell 0.3.1). Notes for changing the code are in [`.memory/`](../.memory/index.md).

- [Using it](usage.md): opening it, tiles, search, keyboard shortcuts, the strip, the ⚙ menu and profiles.
- [Opening effects](effects.md): the twenty effects, where they start from, duration and closing.
- [Configuration](configuration.md): `config.toml`, profiles, the usage history, import and export.
- [Architecture](architecture.md): the files, the windows, colours, focus, effects and how state is saved.
- [Development](development.md): install loop, tests, and the traps found so far.
